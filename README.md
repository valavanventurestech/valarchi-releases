# Valarchi for Android

Download the latest app: **[valarchi.apk](https://github.com/valavanventurestech/valarchi-releases/releases/latest/download/valarchi.apk)**

Valarchi brings your tasks, habits, money and wealth together, built for Indian freelancers.
Also on the web at [valarchi.net](https://www.valarchi.net).

## Install

1. Download `valarchi.apk` on your Android phone (Android 7 or newer).
2. Open it. If asked, allow your browser or file manager to install apps.
3. Sign in with your Valarchi account.

**Updating from version 1.x:** the app is now signed with a new key, so uninstall
the old Valarchi app first, then install this one. Your data is safe: it lives in
your Valarchi account, not on the phone.

Each release lists the APK's SHA-256 checksum so you can verify the download.

This repository only hosts release files. The app's source code is private.
